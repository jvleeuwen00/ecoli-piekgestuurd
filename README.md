# ecoli-piekgestuurd

Simple starter setup for working with notebooks using [pixi](https://pixi.sh/).

## Quick start

```bash
pixi install
pixi run python -m ipykernel install --user --name ecoli-piekgestuurd
```

Place notebooks in `/home/runner/work/ecoli-piekgestuurd/ecoli-piekgestuurd/notebooks`.

Project data is expected to stay on the shared company drive and is not tracked in this repository.
